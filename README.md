# 🚗 Car Dekho Website

Welcome to **Car Dekho** – your one-stop destination to explore and admire cars! Whether you’re a car enthusiast or just curious, this website makes browsing cars fun and interactive.  

---

## ✨ Project Overview
**Car Dekho** is a responsive HTML & CSS website designed to showcase different car models with sleek layouts, attractive visuals, and smooth navigation. No frameworks, just pure HTML & CSS magic!  

---

## 🎯 Features
- **Responsive Design:** Looks great on desktops, tablets, and mobiles 📱💻  
- **Car Gallery:** Stunning images and brief details of each car 🚘  
- **Navigation Bar:** Easy-to-use menu for smooth browsing 🧭  
- **Hover Effects:** Interactive buttons and cards for better UX 🎨  
- **Footer Section:** Contact info & social links 🌐  

---

## 🛠 Technologies Used
- HTML5  
- CSS3  
- Flexbox & Grid Layouts  
- Media Queries for responsive design
