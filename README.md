Car Dekho Website – HTML & CSS Final Project
🚗 Overview

Car Dekho Website is a simple and user-friendly car listing project built using HTML5 and CSS3.
The website displays various cars along with their images, features, and prices.
It is designed as a frontend-only static website for educational and practice purposes.

📌 Features

✔️ Clean and modern UI

✔️ Homepage with banner and navigation

✔️ Car listing with images and prices

✔️ Individual car details section (optional)

✔️ Contact form for user queries

✔️ Responsive layout using CSS

🛠️ Technologies Used

HTML5 – Page structure

CSS3 – Styling and layout (Flexbox/Grid)

📂 Project Structure
/car-dekho-website
│── index.html
│── cars.html
│── contact.html
│── style.css

🎯 Objective

The purpose of this project is to create a visually appealing and easy-to-navigate car showcase website using only HTML and CSS.
It demonstrates basic web design skills including layout, styling, and component structuring.
